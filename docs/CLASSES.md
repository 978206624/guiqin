# 职业与技能

## 创角与入派
创角页只有两个角色：**新手（男）** 和 **新手（女）**，造型参考 kunkunxunqin 创角预览里的「赤绳少年」「青带少女」（参考图 `art-src/ref/kunkun_novice_*.png`，原资源见 kunkunxunqin 仓库 `design/role-create-20261008`），用本游戏的手绘画风重画（美术 `art-src/novice-kk/`，提示词 `art-src/prompts/k*_nf|nm.txt`，脚本 `tools/gen_novice_kk.sh`）。更早的几版新手图留在 `art-src/novice/`，不参与构建。
两步入派：①新手 10 级后找太虚之林的道家门主「拜入道家」（`ROLE.sect='dao'`，存进角色表，形象换成「道家弟子」：道家服饰、背负并手持箜篌，职业 id `dao_dz` / `dao_dz_m`，素材 `art-src/dao-base/`）；②再去琴魔堂主 / 天音堂主处确认分堂（选定不可改），职业和形象（行走图、战斗背影、立绘、头像）此时才切换（`game.js` 的 `joinDaoTalk` / `pickHallTalk` / `changeClass`）。原作入门 15 级、分堂 30 级，演示只做到 10 级所以都按 10 级。男女新手同一流程。

## 技能修炼
- 技能等级存在存档 `S.skl = {技能id: 等级}`。有门派技能表的职业（道家弟子 / 天音 / 琴魔）必须学过才能在战斗里用；新手用通用技能，仍按人物等级解锁。旧存档按已解锁等级自动算作 1 级。
- 道家门主（道家弟子阶段）：荡魔曲、灵脉曲（`dangmo_fs` / `lingmai_fs`，入道家送 1 级）可升级；道家心法是被动，随人物等级成长，不在这里升级。
- 琴魔堂主 / 天音堂主：本堂 5 个技能，前两个入堂送 1 级，其余去堂主处学习，全部可升级。只能找自己所属分堂的堂主。
- 演示简化（原作耗经验 + 银票、等级上限 8/20、首次学习 14 级）：只耗银两，等级上限 5；首次学习要人物等级达到该技能解锁等级、花费 150×解锁等级；升到 n 级要人物等级 ≥ 解锁等级 + 2×(n-1)、花费 100×n²。技能每升 1 级，威力和疗效 +12%（`game.js` 的 `skillMul`），不改变耗蓝。
- 道家基础「灵脉曲」原作只解除状态不回血，演示里附带 10% 回血，战斗代码才不用新增“纯解除”分支。

## 技能光效与发布方式
- 8 套高清技能光效（`art-src/fx/*.png`，v1 备份在 `art-src/fx/v1/`）：参考 kunkunxunqin 道家技能特效帧（`art-src/fx/ref/`）让图像生成重画，4×2 共 8 帧、黑底；构建时转成透明通道的精灵表 `assets/fx_*.webp`，`game.js` 的 `sheetFx` 在目标身上播放，缺图时退回代码绘制版。
- 发布改为多文件：页面 `dist/pub_index.html`（不带 doctype 的片段）+ `js/*.js` + `assets/*`，`python3 tools/publish_files.py` 可打印文件列表。多文件版背景用高清质量；单文件版（`dist/guiqin.html`）有 16MB 上限，拼 HTML 时按 `LOWQ` 重压背景，已超过 16MB，不再用于发布。
